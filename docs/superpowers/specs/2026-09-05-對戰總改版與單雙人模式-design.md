## 模式選擇彈窗（遊戲化）

- 選歌畫面按「開始遊戲」→ 跳出**置中彈窗**（深色遮罩），兩張**霓虹道具卡片**：
  - **單人**（一人雙手）／**雙人**（左右對戰）
  - 卡片有圖示、hover 發光、選中放大。
- 選定 → 關閉彈窗與選歌畫面 → 進入該模式的**準備階段**。
- 可關閉（✕／點遮罩外）退回選歌。

## 雙人模式（沿用現有）

- 畫面左右切半，兩人各一隻手臂畫圈，兩條計分條（左藍右紅），共用段落表，各自計分，限時比分高者勝。

## 單人模式（新）

- **一人置中**，全畫面單人姿態偵測，同時追蹤**左手 + 右手**（wrist + shoulder）。
- **一條置中能量條** + 一組分數。
- **計分**：兩手都同段落方向畫圈 → 滿速加分；只一手做對 → 半速；都沒做對 → 不加分、combo 歸零。合拍加成、combo 沿用。
- **導引圓**：左手一個、右手一個（固定位置：左圓 `x=W*0.35`、右圓 `x=W*0.65`，`y=H*0.5`），同一段落方向。
- **結束**（無對手）：限時到 → 顯示**最終分數 + 評級 S/A/B/C**（依分數正規化）。
- 準備階段：畫面中央一個方塊，任一手放進維持 5 秒開始。

### 單人計分（純函數，可測）

`scoreStepSingle(state, segDir, omegaL, omegaR, dt, bpm, cfg)` → `{score, combo}`：
- 休息段（`segDir==='S'`）：保留 combo、不加分。
- `correctL = direction(omegaL,deadzone)===segDir`，`correctR` 同理；`n = correctL + correctR`。
- `n===0` → `combo=0`，不加分。
- 否則：`combo += dt`；`mag =` 做對那些手的 `|omega|` 最大值；`onTempo` 用 `mag` 判定；
  `score += baseRate * dt * (n/2) * tempoMult * comboMultiplier(combo)`。

### 評級（純函數，可測）

`gradeFor(score, roundSec, cfg)` → `'S'|'A'|'B'|'C'`：
- `ratio = score / (cfg.baseRate * roundSec)`（正規化掉時長）。
- `ratio >= cfg.gradeS(1.5)` → S；`>= cfg.gradeA(1.0)` → A；`>= cfg.gradeB(0.5)` → B；否則 C。

## 對戰畫面總改版（兩模式共用）

- **#3 隱藏攝影機**：正式開打後攝影機透明度 → 0，背景只剩 **MV** + **手掌亮點** + **導引圓** + **HUD**（讓玩家欣賞 MV）。準備階段仍顯示攝影機（要看到自己把手放進方塊）。
- **#1 導引圓固定**：不再跟肩膀飄；雙人＝各側中央（`W*0.25`/`W*0.75`），單人＝左右手兩圓（`W*0.35`/`W*0.65`）。手舉高舉低都能偵測（`pickArm` 不限高度）。
- **#4 Combo 華麗爆發**：combo 倍率升級時 → 全屏閃光 + 該側粒子爆發 + 「COMBO xN!」放大彈出 + **上行音效**（WebAudio，接 sfx.js）。
- **#5/#6 遊戲化能量條**：側邊直立「能量管」— 頭像 + 分節發光填充（分數/scoreForFullBar）+ 即時分數數字 + 🔥combo 倍率徽章。雙人左藍右紅；單人置中一條。
- **#8 段落 8 秒**：段落長度改 ≈ 8 秒（對齊節拍）。
- **#2 結束**：時間到 → **停 MV/音樂**（`mvVideo.pause()`）→ 全屏結算：雙人＝勝方+比分；單人＝分數+評級。停留數秒後回選歌。
- **校名**左上常駐。

## 選歌畫面遊戲化

- **背景**：codex 生成的霓虹舞台圖（`public/select-bg.png`），唱片嵌入中央光環。
- **試聽演唱會體積光**：canvas 光引擎（`mix-blend-mode:screen`）——多道光束從上打下緩掃、**浮塵粒子被光照到變亮**、光落點把背景打亮；**只在試聽播放時**亮起。
- **#18 音波不重疊**：點陣音波移到**最底獨立帶（限高 ~11vh）**，按鈕/圓點/資訊全在其上，保證不重疊。
- 唱片光暈、按鈕發光 hover、排版收整（更遊戲感）。
